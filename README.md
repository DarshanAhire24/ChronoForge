🎮 ChronoForge

Journey Through India's Civilization, History & Culture

ChronoForge is an interactive educational game that takes players on a journey through India's rich history, civilization, and cultural heritage.

The project combines gaming, exploration, storytelling, and interactive learning to make Indian history more engaging for students and young learners.

🚀 Live Prototype

🎮 Play ChronoForge:
https://darshanahire24.github.io/ChronoForge/

💡 Project Idea

Traditional history learning can sometimes feel difficult or less engaging. ChronoForge transforms historical learning into an interactive experience where players can explore different periods, discover cultural elements, and learn through gameplay.

✨ Features

- 🎮 Interactive gameplay
- 🏛️ Explore historical and cultural environments
- 📚 Learn about India's civilization and history
- 🗺️ Journey through different historical periods
- 🏺 Interactive museum/exploration section
- 🎯 Story-based learning
- 🧑‍🎓 Designed for students and young learners
- 💻 Web-based prototype

🕹️ Gameplay

Players can:

1. Start the game using PLAY.
2. Explore the virtual environment.
3. Discover historical and cultural elements.
4. Complete activities and explore the journey.
5. Learn about India's history through an interactive experience.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- GitHub Pages

🎯 Objectives
